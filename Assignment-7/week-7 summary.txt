## Assignment Summary

In this assignment, I learned how to work with data in Databricks using PySpark and Delta Lake. I started by loading a CSV dataset and checking its schema to understand the data structure. Then, I cleaned the data by removing null values and duplicate records to make it more reliable for processing. After that, I converted the cleaned data into a Delta table and learned how Delta Lake helps in managing data efficiently. I also created an incremental dataset, updated some existing records, and added a new record to simulate real-world data updates. Using the merge operation, I combined the incremental data with the existing Delta table without creating duplicate records. Finally, I validated the results by checking row counts, verifying duplicates, and reviewing the final schema. This assignment helped me understand how data cleaning, Delta tables, and incremental data processing are used in real-world data engineering workflows.
